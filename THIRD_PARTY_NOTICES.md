# Third-party sources and license scope

## Connor

The 130 samples in the Connor benign subset are derived from the open-source [Connor project](https://github.com/yiheng98/Connor), specifically its [benign dataset](https://github.com/yiheng98/Connor/tree/main/Dataset/Benign). They are imported research material, not outputs of this project's harness + LLM construction workflow.

The associated work is [From Component Manipulation to System Compromise: Understanding and Detecting Malicious MCP Servers](https://arxiv.org/abs/2604.01905). Acknowledge Connor and its upstream projects when using this subset. Source notices already present in the snapshot are retained.

## Sentinel

The 210 Sentinel benign samples retain their existing source labels, upstream `repo_url`, `commit_sha` and other collection metadata. Refer to the per-sample rows in `benchmark/ground_truth/benign_sentinel/labels.jsonl` for upstream attribution. The subset name identifies the collection source and does not imply that its samples were generated by this project.

## License scope

The root Apache-2.0 license covers this project's original code and original metadata, including project-authored sample code. It does not replace licenses or terms applying to imported third-party material. Preserve the existing upstream notices when redistributing those files. The `license` field in historical Sentinel metadata is a filename, not a normalized SPDX identifier.

Codex, Hermes and GLM-5.2 are named to describe the researcher's workflow. Their software and models are not distributed by this repository, and attribution does not imply endorsement.
